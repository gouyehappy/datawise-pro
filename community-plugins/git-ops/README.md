# Git Ops

本机 Git 工作区：连接页只配 **git 可执行文件**。目标是比 SourceTree 更快、更顺手。

## 相对 SourceTree 的优势

| 能力 | SourceTree | Git Ops |
|------|------------|---------|
| 块级暂存 / 丢弃 | Stage Hunk / Discard Hunk | Diff 内「暂存此块 / 丢弃此块」 |
| 勾选暂存 | 文件勾选即 stage | 同样；分区勾选 = 全部 |
| 提交并推送 | 分两步 | **提交并推送** 一键 |
| 键盘 | 有限 | `j/k` · `Space` · `c` · `a` · `Ctrl+Enter` · `?` |
| Pull | 对话框 | 分裂按钮：单击拉取；▾ / 右键 `--rebase` |
| 配色 | 独立皮肤 | **跟随宿主** `--dw-*` |
| 约定式提交 | 无 | feat/fix/docs… 芯片 |
| 体量 | 独立重量级客户端 | 嵌入 DataWise 插件 |

## 布局

顶栏切仓库 · 左分支树 · 可筛选变更 · 可拖宽 Diff（含块操作）· 底栏提交

插件 id：`io.datawise.community.git-ops` · 版本 `0.12.23` · Host API `^1.5`

## 打包

```bash
node community-plugins/git-ops/package.mjs
```

## 右键能力（摘要）

| 对象 | 操作 |
|------|------|
| 文件 | 暂存/取消、复制路径、加入 .gitignore、丢弃修改 |
| Diff 块 | 暂存此块 / 取消此块 / 丢弃此块 |
| 分支 | 切换、合并、新建、重命名、Push、删除 |
| 远程 | Fetch、Push、复制 URL |
| Stash | Apply / Pop / Drop |
| 历史 | 复制 hash、新建分支、检出、Cherry-pick、Revert、Reset |
| 提交按钮 | 提交、提交并推送、Amend |
| Pull | ff-only / rebase（▾ 菜单） |
